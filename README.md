# Retail Sales Performance & Profitability Analytics

## Project Overview

This project analyzes retail sales performance and profitability
using Microsoft Power BI.

## Objectives

- Monitor total sales, profit, orders and profit margin
- Compare sales performance across 2024 and 2025
- Analyze sales by region, category and channel
- Analyze customer segments and products
- Compare monthly sales with sales targets
- Identify regions performing below target

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
